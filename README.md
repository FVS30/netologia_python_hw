\# 📚 Python Data Analytics Homeworks



Репозиторий содержит мои выполненные практические задания и учебные задачи по курсу анализа данных на Python.



\---



\## 📁 Структура репозитория



\* \*\*`python\_base/`\*\* — фундаментальный Python: типы данных, управляющие конструкции, функции, работа с файлами (`open`, `read/write`), обработка исключений (`try-except`) и основы ООП.

\* \*\*`numpy\_and\_pandas/`\*\* — работа с табличными данными: фильтрация, группировка, агрегация, вычисляемые столбцы, применение пользовательских функций и объединение DataFrames.

\* \*\*`stat\_in\_python/`\*\* — прикладная статистика: выявление и обработка аномалий, исследовательский анализ данных (EDA), проверка статистических гипотез и анализ A/B-тестов.



\---
